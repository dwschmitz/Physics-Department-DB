What the file should look like

The first row holds column headings, and each following row is one student. For an Excel file the first sheet is read. Headings are matched loosely (capitalisation, spacing and notes in brackets are ignored), and other columns are ignored.

ColumnNotes
First Name, Last NameRequired.
UCIDRequired: the University ID, exactly 8 digits.
CNETOptional. Stored in lowercase.
EmailRequired. Each student needs a different email address.
CitizenshipRequired: Citizen, Permanent Resident or International.
Matriculation Year, Matriculation QuarterRequired: a four-digit year, and Autumn, Winter, Spring or Summer.
Transfer, Transfer Year, Transfer QuarterOptional. Transfer is 1 (yes) or 0 (no); a transfer student also needs the year and quarter.
Research Area, NotesOptional.

Imported students are set to Active. A student whose UCID is already in the database is skipped, and the existing record is left unchanged. Advisors and milestones are not imported. Download a blank template (CSV).
